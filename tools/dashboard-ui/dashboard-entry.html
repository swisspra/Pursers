One outcome-oriented path

How Pursers works

  1. Connect a door. An operator pastes a door once; the secret is never shown again in this View.
  2. Start a Team. One folder per teammate, a monitor-only lead, and dispatch that comes from the board.
  3. Describe work. Work is described in agent chat; this preview only reads the authorized projection.
  4. Watch progress. Home and Work show status, ownership and review readiness as bounded data.
  5. Answer an approval. Approvals lists what waits on human judgment and says where the action lives.
  6. Receive a reviewed result. The latest reviewed handoff appears on Home and in Activity relationships.
