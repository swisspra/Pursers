Supported boundaries

Technical details are available here without exposing connection secrets.

Pause

Pause sends a checkpoint message by interrupting one active teammate turn. It does not pause the whole board.

Stop

Stop requests cooperative shutdown. A teammate may reject the request, so the UI reports “requested” until roster state changes.

Resume

The agent-facing host contract has no Team resume operation. Restart or continue the teammate from AionUi; this page will not claim an unsupported resume.
