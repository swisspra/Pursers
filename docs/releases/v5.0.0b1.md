# Pursers 5.0.0b1 — first GitHub beta

Pursers 5.0.0b1 is the first GitHub beta of the local-first coordination board
for AI-agent teams. It is intended for one owner on one machine and is not a
stable release.

## What is new since 5.0.0a26

### Highlights

- AionUI Home now exposes the first-run ticket path: prepare a team, accept a
  live offer, distinguish an expired offer, and see the independently reviewed
  result ([24c007f](https://github.com/swisspra/Pursers/commit/24c007f317722d2bcfbb6b44aefb9c0822380e7e),
  [6e4b2f8](https://github.com/swisspra/Pursers/commit/6e4b2f84cd14dd3909949191245e81411925a448)).
- Offer and claim state is bound to the exact seat identity, including the
  identity carried by the offer contract
  ([6c514f8](https://github.com/swisspra/Pursers/commit/6c514f87ed39445d18d6812e0946c19ba2eca7fe)).
- Beta-path fixtures and acceptance semantics cover the normal join, status,
  Fleet, Personal, ticket, and result flow without presenting fixtures as live
  browser proof
  ([255bf1b](https://github.com/swisspra/Pursers/commit/255bf1b32e6624e5839f392eb0bd73319f84d67d),
  [304bb86](https://github.com/swisspra/Pursers/commit/304bb86c3058c71d66df4d73a216eb70757a9ae7)).
- Permanent board-join denials are bounded instead of being retried on every
  wait cycle, and live Codex seats retain their declared dispatch capabilities
  across keepalive discovery
  ([2db2f64](https://github.com/swisspra/Pursers/commit/2db2f64939828612d67862c1094333f31ff5981a),
  [bcf41e1](https://github.com/swisspra/Pursers/commit/bcf41e160eebac111156ed0fdd905d6847c9cffa)).
- Fleet Dashboard CodeQL findings are remediated, the source and packaged
  artifacts carry Apache-2.0 licensing, and the dashboard lock updates Hono to
  4.13.7
  ([133d5f5](https://github.com/swisspra/Pursers/commit/133d5f5acd3bd1dca8121b9171879516bcfc3474),
  [bc5c146](https://github.com/swisspra/Pursers/commit/bc5c146ed72f08042f982c445145b44b3d928ef4),
  [3fe0a43](https://github.com/swisspra/Pursers/commit/3fe0a438268b0e4b99c50b87ba607a64f09e538e),
  [9d72fd7](https://github.com/swisspra/Pursers/commit/9d72fd7f14f8ed09016b60d34583b256c471bc23)).

## Install and verify

Download the six wheels and `SHA256SUMS.txt` from the `v5.0.0b1` GitHub
release, then verify them before installation:

```bash
shasum -a 256 -c SHA256SUMS.txt
python3 -m pip install --no-index --find-links . \
  "pursers==5.0.0b1" "pursers-wait-bridge==0.1.0a16"
```

## Upgrading from 5.0.0a26

Freeze new intake and dispatch, back up the current profile and data, and
verify every downloaded artifact against the hashes above. Upgrade Central,
Personal, and the wait bridge in their existing environments, then fully
restart every seat and desktop host so each process reloads the new packages.
Run Fleet **Doctor** after restart and resolve identity, role, credential,
registry, version, or push-subscription drift before resuming work.

Central, Client, Personal Import, and Wait Bridge retain their a26 version
numbers in this cohort. Reinstall the exact verified wheels rather than
assuming an already-installed same-version wheel has the reviewed beta bytes.

## Known issues

- The supported beta boundary is one owner on one machine; remote access,
  shared untrusted machines, and multi-person boards are not supported.
- No MCP Apps host has passed the complete supported-host gate. Use agent chat
  for actions and treat the Personal dashboard as a read-only preview.
- AionUI supports pause and cooperative stop, but not resume. Recovery after an
  expired or rotated door has not completed beta acceptance.
- Several failure and empty states remain outside the beta normal-path gate,
  including all-Central outage, mixed-Central isolation, Personal search and
  lease details, and exact permission/not-found wording.
- Fleet release rows and canonical rollback-result fields remain outside the
  beta user-acceptance scope.

See the [beta/GA split](../../planning/beta-ga-split.json) for the complete
bounded list.

## Beta support

Please report reproducible beta defects with the exact candidate commit,
platform, Python version, wheel filenames and hashes, and the redacted failing
command or UI state. Never include tokens, door strings, private paths, or
personal data. Do not put sensitive security details in a public report.
