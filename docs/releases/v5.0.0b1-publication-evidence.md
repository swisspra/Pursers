# Pursers 5.0.0b1 publication evidence

This record verifies the GitHub publication of Pursers 5.0.0b1 from public
GitHub data and fresh downloads on 2026-09-14. It does not authorize or record
a PyPI publication or production cutover.

## Published source and tag

The release candidate is
[`dc5847395e619359f6ba06e6f8d19fd2a7ec7bd5`](https://github.com/swisspra/Pursers/commit/dc5847395e619359f6ba06e6f8d19fd2a7ec7bd5).
The public Git ref `refs/tags/v5.0.0b1` points to annotated tag object
[`2051bdd402c530204012d39cb17b366a0c268d9f`](https://api.github.com/repos/swisspra/Pursers/git/tags/2051bdd402c530204012d39cb17b366a0c268d9f),
which points to that exact candidate commit.

The annotated tag is unsigned: GitHub reports `verified=false` and
`reason=unsigned`. This is an explicit release-host limitation, not a claim of
a signed release. The preceding `v5.0.0a25` and `v5.0.0a26` refs are lightweight
tags whose public ref objects point directly to commits.

## GitHub release state

The [GitHub release](https://github.com/swisspra/Pursers/releases/tag/v5.0.0b1)
was published at `2026-09-14T14:42:52Z`. Final public-API verification at
`2026-09-14T17:02:27Z` reported `draft=false`, `prerelease=true`, and seven
assets. The repository's `releases/latest` endpoint returned HTTP 404, so no
stable Latest release is advertised.

There was a post-publication flag incident. The release was initially verified
as a prerelease that was not Latest after publication. At
`2026-09-14T16:13Z`, a fresh public-API check instead found
`prerelease=false`, and `releases/latest` resolved to `v5.0.0b1`. The cause
was an operator UI edit. It was corrected within the same operator session.
The release API records `updated_at=2026-09-14T17:01:27Z`, and the independent
`2026-09-14T17:02:27Z` check confirmed the final state above. No asset, tag, or
release-body change was required for the correction.

The tag-triggered
[`release` workflow run 34857373433](https://github.com/swisspra/Pursers/actions/runs/34857373433)
completed successfully at the exact candidate SHA. It published exactly seven
assets: six wheels and `SHA256SUMS.txt`.
